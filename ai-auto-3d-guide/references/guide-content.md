# AI 与机械设计：用大模型驱动 SolidWorks / CAD 使用指南

> 本文档内容来自飞书在线文档《AI 与机械设计：用大模型驱动 SolidWorks / CAD 使用指南》的完整打包，供 AI Agent 直接读取并按步骤引导用户执行。

**这份指南适合谁：** 机械工程师、AI 学习者、想了解「AI 怎么参与机械设计」的。

**怎么读：** 先看第一章了解三条玩法并选一条路线，二到四章是可直接照做的教程，最后用资源清单和参考资料回溯原文，结尾附 AI 能力边界的延伸思考。

## 1. 三条主流玩法：怎么让大模型帮你画图

| 玩法 | 驱动对象 | 核心工具链 | 适合场景 |
|---|---|---|---|
| **玩法一：Kimi 自动制作工程图** | AutoCAD / 浩辰 CAD / 中望 CAD | Kimi 桌面版（work 功能） | 2D 工程图 |
| **玩法二：Kimi 驱动 SolidWorks 画 3D** | SolidWorks | Kimi 桌面版（work 功能） | 3D 零件建模 |
| **玩法三：GPT-6 驱动 SolidWorks 画 3D** | SolidWorks | CC-Switch + Codex + GPT-6 | 3D 建模（模型能力极大加强） |

**三条路线的共同逻辑：** 装好 CAD 软件 + 带「工作台」能力的 AI 客户端 → 给 AI「全部允许」的操作权限 → 用自然语言下达画图指令 → AI 自动完成建模或绘图。

## 2. 玩法一：Kimi 自动制作工程图（CAD）

1. **安装软件：** 安装 Kimi + CAD 软件（AutoCAD、浩辰 CAD、中望 CAD 三选一）。
2. **打开 CAD 和 Kimi 并设置：** Kimi 左侧侧边栏点 work → 新建任务 → 左边「全部允许」、右边 K3、思考强度「极致」、对话容量「标准」。
3. **输入指令：** 输入画图要求，点击发送，等待 CAD 完成绘图。

> **可直接复用的提示词示例：** 按制图规范在 CAD 软件中新制作一张工程图：材料 45 钢，外形尺寸 100×100×15，中心开 Ø40 通孔，然后在圆周打 6 个 M5 通孔，圆周阵列均布，均布圆的直径为 Ø70。中心对称的方式打 4 个 M6 沉头孔，位置尺寸 75×75。四个角进行倒角 C3 处理。

- **避坑经验一：** 绘图效果可能不尽如人意，因为此时的 AI 还不太懂绘图规范，需要通过持续对话让 AI 学习经验。
- **避坑经验二：** 用 skill 沉淀经验——把制图规范写成 skill 交给 AI，它才能不断升级绘图技能；作者开源的[制图规范 skill](https://github.com/wumingyu1688-sudo/AI-CADdrawing)可直接丢给 Kimi 下载安装。

## 3. 玩法二：Kimi 驱动 SolidWorks 画 3D 图

1. **安装软件：** 安装 SolidWorks 和 Kimi 桌面版。
2. **打开 Kimi 并设置：** 左侧侧边栏点击 work，选择新建任务；对话框左边选择「全部允许」，右边选择 K3，思考强度选「极致」，对话容量选「标准」。
3. **输入提示词：** 输入画图要求，点击发送，等待 Kimi 完成 3D 建模。

> **重要提醒：** AI 并没有想象中那么强大，不能一句话就画出想要的 3D，短视频里看到的往往是很多次升级迭代后的产品。想真正研究 AI 3D 建模，建议亲手完成一个作品，完成后你会发现它并没有想象中复杂。

## 4. 玩法三：GPT-6 自动调用 SolidWorks 画 3D

1. **安装 CC-Switch，选择 API 供应商：**
   - 前置条件 1：安装 [Node.js](https://nodejs.org/zh-cn/download)（编程运行环境）；
   - 前置条件 2：安装 [PowerShell](https://github.com/powershell/powershell/releases)（Windows 旧版本存在编码问题）；
   - 下载安装 [CC-Switch](https://ccswitch.io/zh/)，打开后点右上角加号进入供应商列表，选一个 API 供应商（教程以「胜算云」为例）；
   - 进入供应商网站注册登录并充值 → 复制 API Key → 回 CC-Switch 粘贴 → 默认模型选 GPT-6 → 保存。
2. **安装 Codex，选择模型等级：** 到 [Codex 官网](https://chatgpt.com/codex/)下载安装；建一个专用项目文件夹存放 GPT-6 产生的文件；推理能力选「高」即可，最高档太消耗 token，没必要。
3. **打开 SolidWorks，输入画图要求：** 等待 GPT-6 完成 3D 建模。

- **体验要点：** GPT-6 的 3D 能力很强，能很好理解需求，基本不需要额外提示词；想要好效果，要把相关数据都给足。
- **兜底：** 安装过程中遇到任何问题，都可以找豆包协助解决。

## 5. 通用配置与提示词要点（三招通用）

- **权限要给够：** Kimi work 任务中左侧选「全部允许」，AI 才能操作 CAD/SolidWorks。
- **模型与参数：** 模型选 K3（Kimi）或 GPT-6（CC-Switch）；思考强度「极致」、推理能力「高」即可，别追求最高档（费 token 且没必要）。
- **数据要给足：** 画图要求越具体（材料、尺寸、孔位、阵列、倒角），AI 输出越接近预期；一句话需求只能得到粗糙结果。
- **迭代是常态：** 一次成图是运气，多轮对话 + skill 沉淀才是稳定出图的关键。

## 8. 延伸学习建议

1. **动手优先：** 选一个简单零件（如法兰盘、支架），用 Kimi + SolidWorks 完整走一遍「装软件 → 设权限 → 给数据 → 出模型」流程。
2. **沉淀 skill：** 把自己常用的制图规范、提示词整理成 skill，让 AI 越用越懂你。
3. **关注边界：** 把 AI 当「出图员 + 资料员」，把工程判断力（需求拆解、约束权衡、责任）留给自己。
4. **关注迭代：** AI 客户端和 CAD 软件都在快速迭代，方法不绑定具体版本，留意官方更新即可。

## 9. 延伸思考：AI 能替代机械工程师吗？

**结论：不能。** AI 是工程师的高效助手，不是替代者。理解 AI 的边界，比学会操作更重要——它负责「画得快、查得准」，判断与担责仍属于工程师。

### 一句话总结 AI 的边界

- **能做的四件事：** 出图（工程图、3D 图、图纸转 CAD）、出文档（BOM、技术文档）、查低级错误、检索资料（机械手册、计算选型）。
- **不能做的四件事：** 理解客户真实需求、定义优化边界与优先级、学习多学科系统集成的默会知识、为机器担责（最致命）。
